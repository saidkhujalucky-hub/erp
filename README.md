# Easy Plast ERP

Лёгкая ERP для производства полиэтиленовых пакетов. Один файл `index.html`, без сборки и серверов.

## Процесс

Заказ → проверка маржи, кредитного лимита и просрочек → (согласование финдиректора) → закупка сырья → экструзия → печать → резка → **предоплата 30%** → УПД и отгрузка → оплата 70% через 30 дней.

## Возможности

- Заказы с автоматической проверкой маржи (порог 15%), лимита и просрочек клиента
- Согласование или отказ финдиректора
- Печать только после предоплаты 30% (настраивается галочкой)
- Отгрузка заблокирована, пока нет 30%
- Клиенты и кредитные лимиты
- График платежей и просрочка, прогноз поступлений на 7 и 30 дней
- Резервная копия: «Скачать копию» и «Загрузить копию» (JSON)

## Запуск

Откройте `index.html` в браузере. Данные хранятся в `localStorage` этого браузера, поэтому регулярно скачивайте копию.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

```bash
git init
git add .
git commit -m "Easy Plast ERP"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/easy-plast-erp.git
git push -u origin main
```

## Ограничения

- Данные не общие: каждый браузер хранит свои. Для работы нескольких сотрудников нужна база данных (например, Supabase или Firebase) и вход по ролям.
- Нет склада сырья, ОТК, печати УПД и автонапоминаний клиентам.
